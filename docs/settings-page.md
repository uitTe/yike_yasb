# 可视化配置页面

右键点击 YASB 托盘图标，选择“打开配置页面”。该按钮位于“打开配置文件夹”上方。

页面采用深色侧边导航，包含概览、状态栏和已添加的组件。点击“添加组件”，可以浏览全部组件的中文名称和用途，也可以通过中文或英文名称搜索。选择目标状态栏及左侧、居中或右侧位置后，程序自动生成组件名称并完成添加。

组件页面仅显示需要用户提供的必要信息。例如 Codex 用量只需填写 Codex 程序路径，天气服务只需填写服务密钥和城市，服务器监控只需填写地址。处理器、内存、音量等组件无需配置。标签、样式、动画、刷新间隔等选项由默认值和已有配置管理。

状态栏页面可以控制显示、选择显示器与顶部或底部位置，以及调整组件顺序、移除组件。添加组件或启用状态栏时，空的显示器列表会自动设置为全部显示器。

页面读取程序目录中的 `defaults/config.yaml`。修改后点击“保存配置”或按 `Ctrl+S`，配置通过校验后写入文件，保留 YAML 注释、引号和所有未编辑的选项。删除组件时同步移除状态栏及分组中的引用。文件被其他程序修改时，页面提示重新读取，防止覆盖其他修改。关闭窗口时会提示处理尚未保存的内容。

点击侧边栏的“English”或“简体中文”按钮，可以立即切换窗口和弹窗的语言。保存后，YASB 界面也会使用所选语言。开启 `watch_config` 时，YASB 自动应用保存的修改；关闭配置监听时，通过托盘菜单重新加载 YASB。

配置窗口由独立的 `yasb_settings.exe` 运行，YASB 重新加载期间可以继续编辑。重复点击托盘入口会显示已经打开的配置窗口。

CSS 样式仍由同目录中的 `styles.css` 管理。
