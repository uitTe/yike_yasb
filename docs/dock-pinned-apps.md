# Dock 固定应用

开始按钮始终位于 Dock 的第一个位置，使用与固定应用相同的图标尺寸。点击按钮执行 Windows 开始操作。

按住固定应用图标并拖动，可以调整应用顺序。拖动时显示插入位置。开始按钮保持原位，应用可以放在开始按钮之后的第一个位置。双屏 Dock 共用排序，支持跨显示器拖动。

右键点击应用图标，选择“从 Dock 取消固定”，即可从 Dock 移除该应用。开始按钮始终保留。

应用顺序与取消固定结果保存在程序目录的 `data/windows_pinned.json` 中，重启后恢复。设置 `YASB_DATA_HOME` 时，数据文件保存在指定目录。保存使用 QSaveFile 原子写入。
