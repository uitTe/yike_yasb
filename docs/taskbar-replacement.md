# Dock 接管系统任务栏

在底部栏的 `window_flags` 中设置 `hide_windows_taskbar: true`，YASB 在 Dock 及组件创建成功后隐藏全部显示器上的 Windows 任务栏。默认配置的 `macos-dock` 已启用此设置。

应用管理层统一启动 `yasb_taskbar.exe`。该进程记录原有任务栏可见状态和自动隐藏设置，通过窗口显示事件和定时检查维持接管，并跟随 Explorer 重新创建的任务栏窗口。

YASB 正常退出时通知恢复进程恢复任务栏；YASB 被强制结束时，恢复进程通过 Windows 进程句柄感知退出并恢复状态。配置重载时，旧恢复进程完成退出后，新恢复进程才开始接管。

Explorer 继续运行，为桌面、文件资源管理器及现有系统托盘集成提供服务。任务栏窗口在接管期间保持隐藏。

将 `hide_windows_taskbar` 改为 `false` 或禁用相应底部栏后，配置重载会恢复系统任务栏。只有已经显示并包含组件的底部栏可以请求接管。
